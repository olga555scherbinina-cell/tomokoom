Кроссбраузерное тестирование

📌 Тестирование проводилось на разрешении 1920×1080px:

Firefox Chrome Edge Avast Opera Яндекс

📋 Выводы

  1. 🦊 Firefox (Gecko) — лучшая адаптация под 1920×1080px. Единственное отклонение — оттенок кнопки (#00db01 вместо #00db00), не критично.
  2. ❌ Браузеры на Blink (Chrome, Edge, Opera, Яндекс, Avast) — общая проблема выхода контейнеров за область видимости. Нужны медиазапросы для больших экранов.

💡 Рекомендации

  • Добавить медиазапросы для 1920px
  • Пересмотреть отступы и поля контейнеров
  • Использовать vw/vh вместо фиксированных px

Это позволит сайту выглядеть одинаково качественно в любом браузере.

Задание 6. UI-тестирование

📋 Итоги UI-тестирования

Выявлено 9 ключевых проблем на сайте «Школы 21».

Основные категории:

  1. Загрузка изображений (UI-001, 003, 005, 006) — некорректные пути. Заменить на абсолютные URL.
  2. Вёрстка и позиционирование (UI-002, 004, 007) — несоответствие макету. Проверить CSS.
  3. Лишние/отсутствующие элементы (UI-008, 009) — удалить лишнее, добавить блок «Кампусы».

Критично: отсутствие фонового изображения на главной (UI-001).
