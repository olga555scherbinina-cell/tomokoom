📋 О проекте

Стек технологий
Java 21 • JCurses • ООП • Алгоритмы

Консольное roguelike-приложение в духе классической игры Rogue 1980 года. Игра поддерживает разделение на слои (domain, presentation, datalayer), генерацию подземелий, пошаговый режим, 5 типов противников с уникальным поведением, систему боя, инвентарь и туман войны.

🎮 Игровые механики

Геймплей
Что внутри игры
  • 21 уровень подземелий, каждый состоит из 9 комнат, соединённых коридорами
  • 5 типов противников: Зомби, Вампир, Привидение, Огр, Змей-маг — каждый с уникальным паттерном
  • Пошаговый бой: проверка на попадание → расчёт урона → применение урона
  • Инвентарь: еда, эликсиры, свитки, оружие, сокровища
  • Туман войны: Ray Casting + алгоритм Брезенхэма
  • Сохранение: JSON-файл с полным состоянием игры
  • Таблица лидеров: сортировка по количеству сокровищ

📦 Задания проекта

AP1-Jv-P01
8 заданий Java Bootcamp
  1. Сущностные сущности — доменный слой: игровая сессия, уровень, комната, персонаж, противники, предметы, рюкзак
  2. Бодрый геймплей — логика игры: 21 уровень, 9 комнат, 5 типов врагов, пошаговый бой, инвентарь
  3. Сгенерированный мир — генерация уровней: 9 секций, случайные комнаты, связный граф
  4. Ламповое 2D — рендеринг с JCurses: стены, пол, акторы, туман войны, управление WASD
  5. Картридж с батарейкой — сохранение/загрузка прогресса в JSON
  6. Ты не пройдёшь! — двери и ключи (как в DOOM)
  7. Искусство баланса — авто-подстройка сложности
  8. Представь, что ты стол — противник Мимик
