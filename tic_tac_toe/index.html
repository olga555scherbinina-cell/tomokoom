Веб-приложение «Крестики-Нолики» с серверной частью на Spring Framework, JWT-авторизацией, базой данных PostgreSQL. Поддержка многопользовательской игры, таблицы лидеров и истории завершённых игр.

🎮 Крестики-Нолики — Демонстрация игры

Веб-приложение на Spring Boot • JWT-авторизация • PostgreSQL

🔐 Задание 1. JWT-авторизация

  • Переход с Basic Auth на JWT (access + refresh токены)
  • Роли пользователей (USER) с наследованием от GrantedAuthority
  • Модели: JwtRequest, JwtResponse, RefreshJwtRequest
  • JwtProvider: генерация, валидация, получение claims
  • JwtAuthentication, JwtUtil, обновлённый AuthFilter

📊 Задание 2. История игр

  • Дата создания игры
  • Запрос завершённых игр (X_WON, O_WON, DRAW)
  • Endpoint для получения истории по accessToken

🏆 Задание 3. Таблица лидеров

  • Соотношение побед к поражениям/ничьим
  • Сортировка по убыванию
  • Endpoint: топ-N игроков (только для авторизованных)
