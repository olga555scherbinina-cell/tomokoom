Определения

  • HTTP — сетевой протокол (прикладной уровень)
  • TCP/IP — сетевая модель передачи данных
  • IP-адрес (ID) — уникальный идентификатор устройства
  • Маска подсети (маска сети) — 32-битное число, разделяющее IP
  • Веб-стандарты — W3C
  • Бизнес-логика — правила предметной области

ООП в Java, Enum, Generics

ООП

  • Инкапсуляция — скрытие реализации (private + public методы)
  • Наследование — class Child extends Parent {}
  • Полиморфизм — объекты разных классов через общий тип

Enum

public enum Day { MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY }
Day day = Day.WEDNESDAY; day.ordinal(); // 2
Day d = Day.valueOf("WEDNESDAY"); // регистр важен!

Generics

class Box<T> {}; interface Container<T> {}
public <T> void print(T item) {}
class Child<T> extends Parent<T> {}
class Impl<T> implements Container<T> {}

Память в Java

Stack

  • LIFO
  • Статическая память, примитивы, ссылки
  • Автоматически при входе/выходе из метода

Heap

  • Динамическая память, объекты
  • Young Generation — новые объекты
  • Old Generation — долгоживущие

Garbage Collector

  • Автоматически удаляет неиспользуемые объекты
