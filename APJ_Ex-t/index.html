Статус-коды

  • 200 OK — успешный запрос
  • 300 Multiple Choices — несколько вариантов
  • 301 Moved Permanently — перемещено навсегда
  • 401 Unauthorized — не авторизован
  • 403 Forbidden — нет прав
  • 404 Not Found — не найдено
  • 500 Internal Server Error — ошибка сервера

Основные определения

  • HTTP — сетевой протокол передачи данных (прикладной уровень)
  • TCP/IP — сетевая модель передачи данных
  • IP-адрес (ID) — уникальный числовой идентификатор устройства в сети
  • Маска подсети (маска сети) — 32-битное число, разделяющее IP на адрес подсети и адрес узла
  • Веб-стандарты — создаёт Консорциум всемирной паутины (W3C)
  • Бизнес-логика — система правил поведения объектов предметной области

ООП в Java, Enum, Generics

ООП (объектно-ориентированное программирование)

  • Инкапсуляция — скрытие внутренних деталей реализации, доступ через public-методы. Модификатор private делает член класса доступным только внутри самого класса.
  • Наследование — создание нового класса на основе существующего: class Child extends Parent {}
  • Полиморфизм — способность объектов разных классов обрабатываться через общий тип (родительский класс или интерфейс).
  • Абстракция — выделение существенных характеристик объекта.

Интерфейсы

public class ConcreteData implements Data {}

Enum (перечисления)

public enum Day { MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY }

Day day = Day.WEDNESDAY;
System.out.println(day.ordinal());      // 2 (порядковый номер, с 0)
Day d = Day.valueOf("WEDNESDAY");       // регистр важен! "wednesday" — ошибка

valueOf() — статический метод, возвращает константу enum по строковому имени (с учётом регистра).

Generics

class Box<T> { private T value; }
interface Container<T> { T get(); }
public <T> void print(T item) {}
class Child<T> extends Parent<T> {}
class Impl<T> implements Container<T> {}

Память в Java (Stack, Heap, Garbage Collector)

Stack

  • LIFO (Last In, First Out) — последний пришёл, первый ушёл
  • Статическая память: примитивы, ссылки на объекты
  • Выделяется и освобождается автоматически при входе/выходе из метода

Heap (Куча)

  • Динамическая память: Java-объекты, JRE классы
  • Young Generation (Eden + Survivor spaces) — новые объекты
  • Old Generation — долгоживущие объекты

Garbage Collector (сборщик мусора)

  • Автоматически удаляет объекты, на которые больше нет ссылок
  • Работает в Heap, освобождая неиспользуемую память
  • Типы: Serial GC, Parallel GC, G1 GC, ZGC
